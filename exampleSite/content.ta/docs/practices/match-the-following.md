> பொருத்துக (Match the Following) என்பது வெவ்வேறு கருத்துகள், வடிவங்கள் அல்லது கூறுகளுக்கு இடையிலான தொடர்புகளை அடையாளம் காணும் கற்பவரின் திறனைச் சோதிக்கப் பயன்படும் ஒரு செயல்மிகு மதிப்பீட்டுக் கருவியாகும். குறிப்பிட்ட கருவிகளை அவற்றின் அடிப்படைக் கட்டமைப்பு வடிவங்களுடன் இணைக்க அல்லது சொற்களை அவற்றின் வரையறைகளுடன் தொடர்புபடுத்த இந்த வடிவமைப்பைப் பயன்படுத்தவும்.

## தொடரியல்

பொருத்துக கேள்வி இரண்டு YAML புலங்களைப் பயன்படுத்துகிறது:

* `choices`: பொருத்தப்பட வேண்டிய உருப்படிகளை (முன்கூறுகள் அல்லது மூலச் சொற்கள்) பட்டியலிடுகிறது.
* `matches`: அதற்கு இணையான இலக்குகள் அல்லது வரையறைகளைப் பட்டியலிடுகிறது. **`matches` இல் உள்ள உருப்படிகளின் எண்ணிக்கை `choices` இல் உள்ளவற்றின் எண்ணிக்கைக்குச் சமமாகவோ அதைவிட அதிகமாகவோ இருக்கலாம்**; இதனால் கூடுதல் திசைதிருப்பும் (distractor) விருப்பங்களையும் சேர்க்க முடியும்.

கேள்வியை ஆதரிக்கப்படும் எந்த Markdown உள்ளடக்கத்தையும் பயன்படுத்தி எழுதலாம்.

```markdown
---
choices:
- "தேர்வு 1"
- "தேர்வு 2"
matches:
- "பொருத்தம் 1"
- "பொருத்தம் 2"
- "கூடுதல் திசைதிருப்பி"
---

உங்கள் கேள்வியை இங்கே எழுதவும்?

கூடுதல் Markdown உள்ளடக்கத்தை இங்கே சேர்க்கலாம்.

---

சரியான தொடர்புகள் மற்றும் பொருத்தங்களுக்கான விளக்கம்.

```

## பயன்பாட்டு எடுத்துக்காட்டு

பின்வரும் எடுத்துக்காட்டு Java கூறுகள் மற்றும் API-களை அவற்றுக்குரிய வடிவமைப்பு வடிவங்களுடன் (design patterns) பொருத்துகிறது; `matches` பட்டியலில் ஒரு கூடுதல் திசைதிருப்பி விருப்பமும் உள்ளது.

```markdown
---
choices:
- "Collection Streams API"
- "Buffered Reader"
- "Container"
matches:
- "Builder"
- "Decorator"
- "Composite"
- "Singleton"
---

ஒவ்வொரு Java கூறு அல்லது API-ஐயும் அதற்குரிய வடிவமைப்பு வடிவத்துடன் பொருத்துக.

---

- **Collection Streams API** என்பது **Builder** உடன் பொருந்தும் (பைப்லைன் செயல்பாடுகளை சரளமாக உருவாக்கவும் கட்டமைக்கவும் உதவுகிறது).
- **Buffered Reader** என்பது **Decorator** உடன் பொருந்தும் (அடிப்படை ரீடர் ஸ்ட்ரீமைச் சுற்றி, பஃபரிங் நடத்தையைச் சேர்க்கிறது).
- **Container** என்பது **Composite** உடன் பொருந்தும் (தனித்தனி உருப்படிகளையும் உள்ளடங்கிய கூறு அமைப்புகளையும் ஒரே மாதிரியாகக் கையாள அனுமதிக்கிறது).

```
